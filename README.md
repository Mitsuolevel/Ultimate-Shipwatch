# Ultimate-Shipwatch

Bring shipwatching into the 21st century.

Ultimate-Shipwatch is a modern digital ship logging and tracking application
designed for shipwatchers, enthusiasts, and maritime historians worldwide.

While the project currently focuses heavily on Great Lakes shipping due to
its Michigan roots, the long-term goal is to support shipwatching and vessel
tracking across all major waterways and regions.

Replace stacks of handwritten logbooks with a powerful mobile-first platform
built for recording ship sightings, cargoes, ports, routes, yearly summaries,
and more.

The project is currently in active development, with a closed beta release
approaching soon.

## Planned Features
- Digital ship sighting logs
- Cargo and route tracking
- Port statistics
- Yearly summaries
- Map integration
- AIS-assisted tools
- Offline support
- Android support via Kivy/KivyMD

## Status
Closed beta preparations are currently underway.
